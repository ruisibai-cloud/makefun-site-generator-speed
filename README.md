A fast drop-in for makefun-site 1.0.0: a dependency-free static site generator (Node 22) that returns byte-identical output for every case, with the work reorganised for speed — bulk HTML escaping, single-pass Markdown rendering, an ASCII fast path for slugs, and a template renderer that walks pre-parsed nodes.

## Run it

```sh
node main.ts
```
